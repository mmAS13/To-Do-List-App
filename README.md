# Smart Task - Modern Todo App
A professional-grade, responsive Todo application built with vanilla HTML, CSS, and JavaScript. Features glassmorphism design, dark mode, local storage, and smooth animations.


# Features
✅ Add Tasks - Quick add with Enter key or button
✏️ Edit Tasks - Modal-based editing with smooth UX
🗑️ Delete Tasks - Animated slide-out deletion
✅ Mark Complete - Custom checkbox with line-through styling
🔍 Smart Filters - All, Pending, Completed views
🌙 Dark/Light Mode - Persistent theme preference
💾 Local Storage - Data persists across sessions
📱 Fully Responsive - Works on mobile, tablet, desktop
🎨 Glassmorphism UI - Modern, professional design
⚡ Smooth Animations - Slide-in/out transitions

# How to Use
Adding Tasks

1. Type task → Press Enter OR click + button
2. Task appears with smooth animation
   
Task Actions

✅ Click checkbox OR task text → Toggle complete
✏️ Click edit icon → Edit in modal
🗑️ Click delete icon → Animated removal

Filters

All → Show all tasks
Pending → Show incomplete tasks
Completed → Show finished tasks

Theme Toggle

☀️ Moon icon → Switch between Light/Dark mode
📱 Responsive Breakpoints
